Flujo de Uso
Acción del Actor Respuesta del Sistema
1. Selecciona "Registrar sección". 2. Muestra un formulario de registro con los campos (Código, cantidad, Año). Valida antes de enviar que el código de sección con el formato correcto (2-3 letras + 4 dígitos) exista.
3. Llena los campos correspondientes a la sección que quiere registrar.
4. Presiona el botón "Registrar". 5. Mensaje "Registro Incluido! Se registró la sección correctamente!"

Validaciones del Sistema

Validación Descripción Mensaje de Error
1. Formato del código Valida formato del código (2-3 letras + 4 dígitos) Formato de código inválido. Debe tener 2-3 letras seguido de exactamente 4 dígitos (ej: IN1101, IIN3104)
2. Cantidad de estudiantes Valida cantidad de estudiantes (0-99) La cantidad de estudiantes debe ser un número entero entre 0 y 99
3. Sección existente Valida que la sección no exista para el año y tipo seleccionado ¡ERROR! La sección ya existe para el año seleccionado. Puede registrar esta misma sección en un período diferente (Regular/Intensivo)
4. Cohorte activa Valida que la cohorte esté creada y activa en la malla Advertencia: La Cohorte no está creada o no está activa en la malla. ¿Desea registrar la sección de todas formas?
